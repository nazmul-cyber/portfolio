## Repos to Push to GitHub

If these projects aren't on GitHub yet, push them:

```powershell
# PV Simulation
cd $env:USERPROFILE\Desktop\pv-panel-simulation
git init
git add .
git commit -m "PV panel output simulation with PyQt6 GUI"
# Create repo on GitHub, then:
git remote add origin https://github.com/YOUR_USERNAME/pv-panel-simulation.git
git push -u origin main

# Todo App
cd $env:USERPROFILE\todo-app
git init
git add app.py requirements.txt README.md templates/
git commit -m "Flask todo app with SQLite"
git remote add origin https://github.com/YOUR_USERNAME/todo-app.git
git push -u origin main

# E-Commerce (exclude secrets!)
cd $env:USERPROFILE\ecommerce
# Make sure .env and firebase-admin.json are in .gitignore first!
git init
git add .
git commit -m "Bubu & Dudu BD e-commerce store"
git remote add origin https://github.com/YOUR_USERNAME/bubu-dudu-store.git
git push -u origin main
```

**Important:** Never commit `.env`, `firebase-admin.json`, or API keys to GitHub.
